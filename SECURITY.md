# Security

HAWL will hold confidential College information. Treat it that way from day one.

## Report a problem
Tell the Tech Lead (Zacki) directly, the same day. Do not post details in public chats or issues.
For a leaked secret, a data exposure, or suspicious access: treat it as a **Critical** incident (see `infra/runbooks/incident.md`).

## Non-negotiables
- No secrets, keys, or real data in the repository, screenshots, or chat.
- Permissions are enforced on the server for every request.
- Production access: maintainer and deputy only, with SSH keys, never shared passwords.
- Every team member signs the confidentiality agreement before touching real data.

The full control list with owners: `docs/security-checklist.md`.
