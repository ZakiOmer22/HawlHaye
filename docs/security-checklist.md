# Security checklist (owner: Zacki; target: signed off before go-live)

- [ ] 1 Argon2id password hashing, min length, common-password check (Zacki, D2)
- [ ] 2 Invite-only accounts, single-use expiring invite (Zacki, D2-3)
- [ ] 3 httpOnly + Secure + SameSite session cookies, idle and absolute timeout, revoke on deactivate (Zacki, D2)
- [ ] 4 Login rate limit and lockout, generic errors (Zacki, D2)
- [ ] 5 RBAC on every endpoint, object-level checks, deny by default, tests per role (Zacki, D3-5)
- [ ] 6 Workflow enforced server-side (Zacki, D4-5)
- [ ] 7 Zod validation on every request, unknown fields rejected (Zacki, Maxamed S)
- [ ] 8 Parameterised queries only; app DB user without admin rights (Maxamed S, Abdiqadir)
- [ ] 9 XSS: React encoding, no raw HTML, CSP header (Maxamed O, Zacki, D6)
- [ ] 10 CSRF token + Origin check (Zacki, D6)
- [ ] 11 Helmet headers and strict CORS (Zacki, D6)
- [ ] 12 HTTPS, redirect, HSTS (Ridwan, D2)
- [ ] 13 Upload allow-list, size cap, content check, random names, private storage, signed URLs (Maxamed S, Zacki, D6-8)
- [ ] 14 Append-only audit trail for tasks and security events (Zacki, Abdiqadir, D4)
- [ ] 15 Secrets only in environment; rotate at go-live (Ridwan, D1, D12)
- [ ] 16 Database not internet-reachable; separate migration user (Abdiqadir, Ridwan, D5)
- [ ] 17 Nightly encrypted backup, offsite copy, restore test recorded (Abdiqadir, Ridwan, D10-11)
- [ ] 18 Lockfile, npm audit in CI, Dependabot (Ridwan, D2)
- [ ] 19 No secrets in logs; no stack traces to users (Zacki, D9)
- [ ] 20 API rate limits, stricter on login/export/upload (Zacki, D8)
- [ ] 21 Access review screen, same-day removal of leavers (Abdimajid, D9)
- [ ] 22 OWASP Top 10 pass, header/TLS scan, role-bypass attempts (Zacki, Ridwan, D10)
- [ ] 23 Two-factor for leadership and admins (Zacki, after launch if time is short)
